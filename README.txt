ETXEKO OBRA — EGUNERAKETA BATERATUA

Incluye:
- Mantiene la base de datos existente etxekoObraDB_v2.
- Importes monetarios que aceptan coma o punto decimal (ej. 3021,63 / 3021.63 / 3.021,63).
- La tarjeta Gastatutako guztia abre Gastuak y es accesible con teclado.
- Saldo restante y avance económico calculados a partir de los gastos, presupuestos aceptados/no rechazados y materiales registrados, sin contar menos que los gastos registrados.
- Botones individuales Ezabatu para adjuntos ya guardados y Kendu para archivos recién seleccionados, sin borrar el registro completo. Los adjuntos marcados se quitan al guardar el formulario; se puede pulsar Berreskuratu antes de guardar.
- Mantiene la galería con Editatu y Ezabatu por fotografía.

Instalación: guardar primero una copia JSON. Sustituir los archivos de la web por los de esta carpeta y hacer Commit changes en GitHub. No borrar datos de Safari ni cambiar el ID de la base de datos.

Nota: probar en el iPad después de publicar. La sintaxis JavaScript ha sido comprobada, pero la aplicación no se ha ejecutado en el dispositivo del usuario.
